# Traini8 - Training Center Registry (MVP)

## Project Overview
This project is an MVP for a **Government-funded Training Center Registry**. It provides two REST APIs using **Spring Boot**:

1. **POST /api/training-centers** → Create and save a new training center.
2. **GET /api/training-centers** → Retrieve a list of all stored training centers.

## Prerequisites
Ensure you have the following installed:
- **Java 17+**
- **Maven 3+**
- **Spring Boot**
- **H2 Database (In-memory for simplicity)**
- **Postman (optional for testing API calls)**

## Setup Instructions

### 1️⃣ Clone the Repository
```sh
git clone <repository_url>
cd traini8
```

### 2️⃣ Build the Project
```sh
mvn clean install
```

### 3️⃣ Run the Application
```sh
mvn spring-boot:run
```
By default, the application runs on **`http://localhost:8080`**.

## API Documentation

### **1️⃣ Create a Training Center (POST)**
#### **Endpoint:**
```http
POST /api/training-centers
```
#### **Request Body (JSON Format):**
```json
{
    "centerName": "ABC Training Center",
    "centerCode": "TC1234567890",
    "address": {
        "detailedAddress": "123 Main St",
        "city": "Hyderabad",
        "state": "Telangana",
        "pincode": "500001"
    },
    "studentCapacity": 100,
    "coursesOffered": ["Java", "Spring Boot"],
    "contactEmail": "abc@example.com",
    "contactPhone": "9876543210"
}
```
#### **Response:**
```json
{
    "id": 1,
    "centerName": "ABC Training Center",
    "centerCode": "TC1234567890",
    "address": {
        "detailedAddress": "123 Main St",
        "city": "Hyderabad",
        "state": "Telangana",
        "pincode": "500001"
    },
    "studentCapacity": 100,
    "coursesOffered": ["Java", "Spring Boot"],
    "createdOn": "2025-02-12T15:10:49.493430100Z",
    "contactEmail": "abc@example.com",
    "contactPhone": "9876543210"
}
```

## Validation & Error Handling
- **Mandatory fields**: Center Name, Center Code, Address, Contact Phone
- **Validation rules**:
  - `centerName` → Max 40 characters
  - `centerCode` → Exactly 12 alphanumeric characters
  - `contactEmail` → Valid email format
  - `contactPhone` → Valid phone number format
  - `createdOn` → Auto-generated by the server (user input ignored)
- **Error Handling:**
  - Errors return `400 BAD REQUEST` with specific field error messages.

## Database (H2 In-Memory)
- The project uses an in-memory **H2 database**, meaning all stored data resets on restart.
